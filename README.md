# 我的记账本

一个简洁的个人记账本应用，包含 **桌面版（Python + tkinter）** 和 **网页版（HTML）** 两种形态，支持收入 / 支出记录、分类管理、按月统计。

## 功能特性

- 收支记录：记录每笔消费与收入，支持自定义金额、分类、备注
- 分类管理：支出（餐饮、交通、购物、居住等 10 类）、收入（工资、奖金、理财等 5 类），每类有专属颜色标识
- 按月统计：切换月份查看当月收支明细与汇总
- 本地存储：数据保存在同目录下的 `账单数据.json`，不依赖网络和数据库

## 目录结构

```
├── 记账本.py          # 桌面版主程序（Python + tkinter）
├── index.html         # 网页版（浏览器直接打开）
├── 启动记账本.bat     # Windows 一键启动脚本
└── 账单数据.json      # 运行时生成的账单数据（不入库）
```

## 使用方法

### 桌面版

需要 Python 3 环境（tkinter 为标准库，无需额外安装依赖）：

- 双击 `启动记账本.bat`，或
- 直接运行 `python 记账本.py`

### 网页版

用浏览器打开 `index.html` 即可，无需任何环境。

## 数据说明

- 账单数据保存在程序同目录的 `账单数据.json` 中
- 该文件为运行时数据，已通过 `.gitignore` 排除，不会上传到仓库

## 技术栈

- 桌面版：Python 3 + tkinter / ttk
- 网页版：原生 HTML / CSS / JavaScript
